# REPKA Project — AI-Native Gantt Planner

Интерактивная диаграмма Гантта с AI-агентом для управления планом проекта на естественном языке.

## Стек

| Слой | Технология |
|------|------------|
| Фронтенд | React 18 + Vite (JSX-компоненты) |
| Бэкенд | Python / FastAPI |
| Протокол интеграции AI | MCP (Model Context Protocol) |
| LLM | OpenRouter API → GPT-4o-mini |
| Данные | Excel (SheetJS xlsx), локальное состояние React |
| Деплой | Render (автоматический из GitHub) |

## Быстрый старт

### 1. Бэкенд

```bash
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

Бэкенд раздаёт React-фронтенд самостоятельно — открой `http://localhost:8000`.

### 2. Переменные окружения

Скопируй `.env.example` → `.env` и вставь свой ключ:

```env
OPENROUTER_API_KEY=sk-or-v1-...
MODEL_NAME=openai/gpt-4o-mini
```

Ключ получить: **[openrouter.ai/keys](https://openrouter.ai/keys)**

### 3. Frontend (Vite-разработка)

```bash
cd frontend
npm install
npm run dev       # dev-сервер с HMR
npm run build     # production-сборка в frontend/dist/
```

### MCP (Model Context Protocol)

Бэкенд реализует MCP-сервер, предоставляющий LLM инструменты для работы с планом:

| Инструмент | Описание |
|------------|----------|
| `add_task` | Создать новую задачу |
| `update_task` | Изменить задачу (название, длительность, исполнителя) |
| `delete_task` | Удалить задачу и её связи |
| `add_dependency` | Создать зависимость между задачами |
| `remove_dependency` | Разорвать связь |
| `complete_task` | Отметить задачу выполненной |
| `list_tasks` | Получить список задач |
| `export_excel` | Экспорт плана в Excel |

### Ключевые алгоритмы фронтенда

- **Планировщик (computeSchedule)** — рекурсивный расчёт дат начала/конца с учётом зависимостей (FS, SS, FF, SF) и защиты от циклических связей.
- **Критический путь (computeCriticalPath)** — прямой + обратный проход по топологически отсортированному графу, поиск задач с нулевым резервом времени (ES == LS).
- **Локальный NLP-парсер (aiProcessCommand)** — обработка русскоязычных команд без бэкенда: добавление, удаление, перенос, назначение, связи, сброс.

## Принятые решения

1. **React + Vite** — сборка через Vite, компоненты в JSX-файлах. Production-сборка раздаётся FastAPI.
2. **Локальный fallback** — если бэкенд недоступен, чат всё равно работает на регулярных выражениях (graceful degradation).
3. **OpenRouter API** — единый API-ключ для доступа к GPT-4o-mini, без привязки к одному провайдеру.
4. **Мульти-проектность** — несколько проектов в одном интерфейсе, переключение через вкладки (как листы Excel).
5. **Типы зависимостей** — поддержаны FS, SS, FF, SF с настраиваемым лагом. Визуализация через SVG с цветовым кодированием.
6. **Ручной/авто режим дат** — можно принудительно задать start_date, сняв авто-расчёт.
7. **Resizable колонки** — drag-and-drop изменение ширины колонок таблицы.

## Использование AI-ассистентов при разработке

Весь проект разработан в диалоге с AI-ассистентом. Ключевые моменты:

- **Архитектура**: AI предложил структуру компонентов React, разделение на GanttChart + ChatPanel + TaskModal + App.
- **Алгоритм планировщика**: AI помог спроектировать рекурсивный вычислитель расписания с защитой от циклов и поддержкой всех 4 типов зависимостей.
- **Критический путь**: алгоритм прямого/обратного прохода реализован совместно с AI.
- **SVG-визуализация зависимостей**: AI спроектировал генерацию кривых Безье для стрелок между задачами.
- **NLP-парсер**: локальный fallback на регулярных выражениях, способный обрабатывать русские падежи, опечатки, частичные совпадения названий задач.
- **MCP-сервер**: AI предложил спецификацию инструментов и их интеграцию с LLM.
- **Excel импорт/экспорт**: SheetJS обёртка спроектирована с учётом формата тестового задания.
- **Стилизация**: тёмная/светлая тема, CSS-переменные, confetti-анимация при 100% выполнении.
- **Деплой на Render**: автоматический деплой из GitHub, настройка через render.yaml.
