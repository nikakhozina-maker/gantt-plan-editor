# Gantt Plan Editor — README

Full-stack AI-native приложение для управления проектными планами через диаграмму Гантта с AI-агентом.

**Стек:** React (фронтенд) + FastAPI (бэкенд) + MCP + LLM

---

## 🚀 Быстрый запуск

### 1. Клонирование
```bash
git clone <repo-url>
cd gantt-plan-editor
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка LLM (опционально)
Создай `.env` файл в корне проекта:
```
OPENROUTER_API_KEY=sk-or-v1-ваш_ключ
```
Поддерживаются: OpenRouter, OpenAI, Anthropic, Gemini.
Без ключа бот работает через локальный NLP (regex).

### 4. Запуск бэкенда
```bash
python main.py
```
Сервер: `http://localhost:8000`

### 5. Запуск фронтенда
Открой `gantt_editor_final.html` в браузере (статический файл на React через Babel).

## 🧠 Архитектура

```
Пользователь → React-фронтенд (диаграмма Гантта + чат)
                    ↓ POST /api/chat
               FastAPI бэкенд
                    ↓
         ┌──── MCP Tool Registry ────┐
         │  add_task / delete_task   │
         │  update_task / add_dep    │
         │  complete_task / ...      │
         └───────────────────────────┘
                    ↓
          LLM API (OpenRouter/OpenAI/...)
                    ↓
          MCP Tools Execute → новые tasks/deps
                    ↓
          Ответ → фронтенд → перерисовка диаграммы
```

### MCP (Model Context Protocol)
Бэкенд реализует MCP-совместимый реестр инструментов:
- `/api/mcp/tools` — список инструментов
- `/api/mcp/call` — вызов инструмента
- LLM получает tools как function calling и автономно решает какие вызывать

### Цепочка LLM
Пробует провайдеров в порядке: OpenRouter → OpenAI → Anthropic → Gemini.
При недоступности всех — локальный NLP (regex) на русском языке.

## ✨ Принятые решения

1. **React через Babel в одном HTML-файле** — для простоты деплоя (нет сборки webpack/vite). Можно открыть как статический файл.
2. **MCP как архитектурный паттерн** — tools описаны декларативно, LLM сама выбирает что вызвать. Легко расширять.
3. **Локальный NLP fallback** — приложение работает даже без API-ключей.
4. **Авто-расчёт расписания** — топологическая сортировка + вычисление start/end дат на основе зависимостей.
5. **Критический путь** — алгоритм нахождения критического пути, подсветка на диаграмме.
6. **Тёмная/светлая тема** — сохранение в localStorage.
7. **Конфетти-анимация при 100%** — позитивное UX-событие завершения проекта.
