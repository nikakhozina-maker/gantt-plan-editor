# REPKA Project — AI-Native Gantt Planner

Интерактивная диаграмма Гантта с AI-агентом для управления планом проекта на естественном языке.

## Стек

| Слой | Технология |
|------|------------|
| Фронтенд | React 18 (CDN, без сборки), Babel Standalone |
| Бэкенд | Python / FastAPI |
| Протокол интеграции AI | MCP (Model Context Protocol) |
| LLM | Через API (OpenAI / Anthropic / локальные модели) |
| Данные | Excel (SheetJS xlsx), локальное состояние React |
| Стили | CSS-переменные, тёмная/светлая тема |

## Быстрый старт

### 1. Фронтенд

```bash
# Открыть в браузере (локально)
open gantt_editor_final.html
# Или через любой статический сервер:
python3 -m http.server 8080
```

### 2. Бэкенд

```bash
cd backend
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Бэкенд поднимается на `http://localhost:8000`. Фронтенд автоматически подключается к нему через `window.__GANTT_API_URL__`. Если бэкенд недоступен — включается локальный fallback-парсер NLP-команд.

### 3. Переменные окружения

```env
# .env в backend/
LLM_API_URL=https://api.openai.com/v1/chat/completions
LLM_API_KEY=sk-...
LLM_MODEL=gpt-4o-mini
MCP_SERVER_ENABLED=true
```

### MCP (Model Context Protocol)

Бэкенд реализует MCP-сервер, предоставляющий LLM инструменты для работы с планом:

| Инструмент | Описание |
|------------|----------|
| `add_task` | Создать новую задачу |
| `update_task` | Изменить задачу (название, длительность, исполнителя) |
| `delete_task` | Удалить задачу и её связи |
| `add_dependency` | Создать зависимость между задачами |
| `remove_dependency` | Разорвать связь |
| `reassign` | Назначить/переназначить исполнителя |
| `list_tasks` | Получить список задач |
| `export_excel` | Экспорт плана в Excel |

### Ключевые алгоритмы фронтенда

- **Планировщик (computeSchedule)** — рекурсивный расчёт дат начала/конца с учётом зависимостей (FS, SS, FF, SF) и защиты от циклических связей.
- **Критический путь (computeCriticalPath)** — прямой + обратный проход по топологически отсортированному графу, поиск задач с нулевым резервом времени (ES == LS).
- **Локальный NLP-парсер (aiProcessCommand)** — обработка русскоязычных команд без бэкенда: добавление, удаление, перенос, назначение, связи, сброс.

## Принятые решения

1. **React через CDN** — чтобы проект запускался без `npm install`/сборки. В продакшене — переезд на Vite.
2. **Локальный fallback** — если бэкенд недоступен, чат всё равно работает на регулярных выражениях. Это демонстрирует graceful degradation.
3. **Мульти-проектность** — несколько проектов в одном интерфейсе, переключение через вкладки (как листы Excel), кросс-проектная фильтрация по исполнителю.
4. **Типы зависимостей** — поддержаны FS, SS, FF, SF с настраиваемым лагом. Визуализация через SVG с цветовым кодированием.
5. **Ручной/авто режим дат** — можно принудительно задать `start_date`, сняв авто-расчёт.
6. **Resizable колонки** — drag-and-drop изменение ширины колонок таблицы.

## Использование AI-ассистентов при разработке

Весь проект разработан в диалоге с AI-ассистентом. Ключевые моменты:

- **Архитектура**: AI предложил структуру компонентов React, разделение на GanttChart + ChatPanel + TaskModal + Main App.
- **Алгоритм планировщика**: AI помог спроектировать рекурсивный вычислитель расписания с защитой от циклов и поддержкой всех 4 типов зависимостей.
- **Критический путь**: алгоритм прямого/обратного прохода реализован совместно с AI, включая расчёт для всех типов связей.
- **SVG-визуализация зависимостей**: AI спроектировал генерацию кривых Безье с закруглёнными углами для стрелок между задачами на диаграмме.
- **NLP-парсер**: локальный fallback на регулярных выражениях, способный обрабатывать русские падежи, опечатки, частичные совпадения названий задач.
- **MCP-сервер**: AI предложил спецификацию инструментов и их интеграцию с LLM.
- **Excel импорт/экспорт**: SheetJS обёртка спроектирована с учётом формата тестового задания (задача, описание, исполнитель, длительность, предшественники).
- **Стилизация**: тёмная/светлая тема, CSS-переменные, адаптивная вёрстка, confetti-анимация при 100% выполнении.
